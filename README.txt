刘文静｜北美创意实验室作品集

打开方式
- 直接打开 index.html 查看完整网站。
- 如果之前的预览标签页显示了旧版，可打开 interaction-preview.html 查看本次更新的卡片交互。
- 直接打开 radar-preview.html 可单独预览粒子雷达。
- 如浏览器限制本地视频播放，可将整个文件夹放在静态网站服务器上运行。

文件说明
- index.html：完整网站，包含首页、创意雷达、案例、协作、作品和联系信息。
- interaction-preview.html：与 index.html 内容相同，使用新文件名避开旧预览缓存。
- public/scripts/：雷达粒子动画、十个可点击标签及分类详情的运行脚本与样式。
- public/videos/ 与 public/posters/：作品视频和封面。
- public/resume.pdf：原有简历。
- radar-particles-src/：雷达 WebGL 粒子组件源代码；浏览网站不需要安装依赖。

雷达页的十个标签会随光点漂移、循环出现。点击标签可查看对应分类介绍和作品视频。
